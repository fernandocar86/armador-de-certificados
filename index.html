Generador de certificados

Todo se procesa en tu navegador: ningún archivo se sube a un servidor.

1. Categorías y modelos

Cada modelo de certificado (.pptx) puede usar hasta tres variables: xxx, yyy y zzz. Escribí el nombre de la categoría tal como aparece en el Excel (ej: “Exposición oral”, "Poster", "Organizador", "Organizadora", etc.) y adjunta en cada caso el certificado modelo para esa categoría en pptx. No hay límite para la cantidad de categorías.

Descargar un certificado modelo

2. Excel de participantes y generación

Se genera un certificado por participante según la categoría declarada (si una celda trae varias, p. ej. “Exposición oral; Póster”, se genera uno por cada una).

Descargar modelo de planilla Excel para cargar participantes

3. Convertir certificados PPTX a PDF

Subí una carpeta con certificados .pptx (o varios .pptx / un .zip) y obtené un .zip con los PDF.

Los PDF se dibujan a partir del diseño del .pptx (imágenes, textos, líneas); es una conversión aproximada. Para fidelidad exacta con fuentes especiales, exportá desde PowerPoint.
